## Publish with GitHub Pages

1. Create a repository named `Viloshini691.github.io`
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder to the repository root
3. Go to **Settings → Pages**
4. Set **Source** to `Deploy from a branch`
5. Select `main` and `/ (root)`
6. Save

Your website will be available at:

`https://Viloshini691.github.io`

## Personalize before publishing

- Add a professional photo under `assets/images/`
- Add your resume PDF under `assets/resume/`
- Add LinkedIn and email to the contact section
- Replace any project URLs if your GitHub repository names differ
